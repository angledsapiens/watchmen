# WM-02 - Normalcy & Baselines (Watchmen)

WM-02 module computes rolling statistical baselines over recent memory.
It does not detect anomalies, trigger alerts, or apply thresholds.

## Responsibilities

- Read memory from Memory module
- Compute rolling statistics per time window
- Expose baselines as reference frames

## Designed to b

- Deterministic
- Recomputable
- Contextual
- Non-judgmental
